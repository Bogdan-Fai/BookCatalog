# Полное объяснение работы программы BookCatalog (4 лабораторная работа по ООП)

## Введение

Этот документ содержит подробное объяснение реализации лабораторной работы №4 по ООП "Каталог книг". Программа BookCatalog демонстрирует работу с базой данных через Entity Framework Core и ADO.NET, импорт/экспорт данных в различных форматах (CSV, JSON, XML) и предоставляет командный интерфейс для управления коллекцией книг.

## Структура заданий

Лабораторная работа состоит из 4 основных заданий, каждое из которых имеет свою реализацию в проекте.

---

## Задание 1: Импорт CSV → ADO.NET → экспорт в JSON/XML

**Цель:** Реализовать импорт данных из CSV файла с использованием ADO.NET и экспорт в JSON/XML форматы.

### Реализация

**Файл:** `4лабаООП/Lab4/BookCatalog/Commands/ImportBooksAdo.cs`
**Строки:** 1-200

**Основные компоненты:**
- Метод `Execute()` (строки 15-80) - основная точка входа для импорта
- Метод `ReadCsvFile()` (строки 85-125) - парсинг CSV файла
- Метод `ReadXmlFile()` (строки 127-155) - парсинг XML файла с валидацией XSD
- Метод `ValidateXmlWithXsd()` (строки 157-195) - валидация XML по XSD схеме
- Метод `InsertBook()` (строки 197-240) - вставка книг в базу данных с обработкой дубликатов

**Ключевые особенности:**
- Поддержка стратегий обработки дубликатов: `update`, `skip`, `merge`
- Транзакционная обработка с возможностью отката при ошибках
- Валидация XML данных по XSD схеме
- Параметризованные SQL запросы для безопасности
- Логирование всех операций и ошибок

### Команды для проверки

```bash
# Импорт из CSV файла с стратегией merge и максимальным количеством ошибок 5
dotnet run import_ado ..\books.csv merge 5

# Импорт из XML файла с валидацией XSD
dotnet run import_ado ..\books.xml update 3

# Просмотр лога операций
type sync.log
```

**Ожидаемый результат:**
- Успешный импорт книг из CSV/XML файлов в базу данных
- Логирование количества обработанных записей, ошибок и стратегий обработки
- Создание или обновление файла `sync.log` с детальной информацией об операции

## Задание 2: Переход к EF Core и реализация CRUD + синхронизация

**Цель:** Реализовать CRUD операции через Entity Framework Core и механизм синхронизации между базой данных и JSON файлом.

### Реализация

**CRUD операции:**

1. **Добавление книги** - `AddBook.cs`
   - **Строки:** 1-50
   - **Команда:** `dotnet run add "ISBN" "Title" "Author" "Year" "Pages"`

2. **Обновление книги** - `UpdateBook.cs`
   - **Строки:** 1-55
   - **Команда:** `dotnet run update "ISBN" "Title" "Author" "Year" "Pages"`

3. **Удаление книги** - `DeleteBook.cs`
   - **Строки:** 1-40
   - **Команда:** `dotnet run delete "ISBN"`

4. **Поиск книг** - `FindBooks.cs`
   - **Строки:** 1-45
   - **Команда:** `dotnet run find "query"`

**Синхронизация:**

**Файл:** `4лабаООП/Lab4/BookCatalog/Commands/SyncBooks.cs`
**Строки:** 1-300

**Основные компоненты:**
- Метод `Execute()` (строки 15-40) - основная точка входа для синхронизации
- Метод `FindDifferences()` (строки 60-100) - поиск различий между БД и JSON
- Метод `ResolveConflicts()` (строки 140-180) - разрешение конфликтов
- Метод `ResolveAutomatic()` (строки 185-240) - автоматическое разрешение конфликтов
- Метод `ResolveInteractive()` (строки 245-300) - интерактивное разрешение конфликтов

**Ключевые особенности:**
- Поддержка стратегий разрешения конфликтов: `ask`, `update_db`, `update_file`, `skip`
- Сравнение данных по ISBN и выявление различий в полях
- Транзакционная обработка с возможностью отката
- Логирование всех операций и принятых решений

### Команды для проверки

```bash
# Добавление новой книги
dotnet run add "1234567890" "C# Programming" "John Doe" "2024" "300"

# Обновление существующей книги
dotnet run update "1234567890" "Advanced C# Programming" "John Doe" "2024" "350"

# Поиск книг по запросу
dotnet run find "Programming"

# Удаление книги
dotnet run delete "1234567890"

# Синхронизация с интерактивным разрешением конфликтов
dotnet run sync ask 5

# Синхронизация с автомаческим обновлением базы данных
dotnet run sync update_db 3

# Просмотр результатов синхронизации
type sync.log
```

**Ожидаемый результат:**
- Успешное выполнение CRUD операций с книгами
- Обнаружение и разрешение конфликтов между базой данных и JSON файлом
- Логирование всех операций синхронизации и принятых решений
- Обновление файла `books.json` текущим состоянием базы данных

## Задание 3: Валидация XML и продвинутая обработка дубликатов

**Цель:** Реализовать импорт из XML файла с валидацией по XSD и продвинутыми стратегиями обработки дубликатов.

### Реализация

**Файл:** `4лабаООП/Lab4/BookCatalog/Commands/ImportBooksAdo.cs`
**Строки:** 127-240

**Основные компоненты:**
- Метод `ReadXmlFile()` (строки 127-155) - чтение XML файла с валидацией
- Метод `ValidateXmlWithXsd()` (строки 157-195) - валидация XML по XSD схеме
- Метод `InsertBook()` (строки 197-240) - обработка дубликатов с различными стратегиями

**Ключевые особенности:**
- Валидация XML данных по XSD схеме (`books.xsd`)
- Логирование ошибок валидации
- Стратегии обработки дубликатов:
  - `skip` - пропуск дубликатов
  - `update` - обновление существующих записей
  - `merge` - слияние данных (использование непустых полей)
- Транзакционная обработка с откатом при превышении порога ошибок

### Команды для проверки

```bash
# Импорт XML файла с валидацией XSD и стратегией merge
dotnet run import_ado ..\books.xml merge 5

# Импорт XML файла с валидацией XSD и стратегией skip
dotnet run import_ado ..\books.xml skip 3

# Просмотр лога валидации
type sync.log | findstr "XML Validation"

# Проверка обработки дубликатов
dotnet run import_ado ..\books.csv update 0
```

**Ожидаемый результат:**
- Успешная валидация XML файла по XSD схеме
- Логирование ошибок валидации (если есть)
- Правильная обработка дубликатов согласно выбранной стратегии
- Обновление базы данных с учетом стратегии обработки дубликатов

## Задание 4: Транзакционная надежность и покрытие тестами

**Цель:** Обеспечить транзакционную надежность операций импорта и синхронизации.

### Реализация

**Транзакционная обработка в ImportBooksAdo.cs:**
- **Строки:** 45-75 (метод Execute)
- Использование `connection.BeginTransaction()`
- Обработка ошибок с `transaction.Rollback()`
- Успешное завершение с `transaction.Commit()`
- Логирование состояния транзакции

**Транзакционная обработка в SyncBooks.cs:**
- **Строки:** 145-175 (метод ResolveConflicts)
- Использование `context.Database.BeginTransaction()`
- Обработка ошибок с откатом транзакции
- Логирование успешных и неуспешных транзакций

**Ключевые особенности:**
- Транзакционный импорт данных
- Откат транзакции при превышении порога ошибок
- Логирование состояния транзакций
- Сохранение целостности данных при ошибках

### Команды для проверки

```bash
# Импорт с транзакционной обработкой и ограничением ошибок
dotnet run import_ado ..\books.csv merge 2

# Синхронизация с транзакционной обработкой
dotnet run sync update_db 3

# Проверка лога транзакций
type sync.log | findstr "COMMITTED\|ROLLED BACK"

# Тестирование отката при превышении порога ошибок
dotnet run import_ado ..\books.csv merge 1
```

**Ожидаемый результат:**
- Успешное выполнение транзакций с логированием состояния
- Откат транзакций при превышении порога ошибок
- Сохранение целостности данных в базе
- Детальное логирование всех транзакционных операций

## Дополнительная информация

### Структура проекта

```
4лабаООП/
├── Lab4/
│   ├── books.csv               - CSV файл с книгами
│   ├── books.json              - JSON файл с книгами
│   ├── books.xml               - XML файл с книгами
│   ├── books.xsd               - XSD схема для XML
│   ├── BookCatalog/
│   │   ├── Commands/           - Команды приложения
│   │   ├── Data/               - Контекст базы данных
│   │   ├── Models/             - Модели данных
│   │   ├── Logger.cs           - Логгер
│   │   ├── sync.log            - Файл лога
│   │   └── Program.cs          - Главная точка входа
```

### Основные файлы данных

- `books.csv` - исходные данные в CSV формате
- `books.json` - данные в JSON формате (используется для синхронизации)
- `books.xml` - данные в XML формате
- `books.xsd` - схема валидации для XML
- `books.db` - база данных SQLite
- `sync.log` - лог операций

### Примеры использования

```bash
# Полный цикл работы с программой
dotnet run import_ado books.csv merge 5
dotnet run export json
dotnet run sync ask 3
dotnet run find "Programming"
```
