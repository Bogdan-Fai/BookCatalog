# Лабораторная работа 4 — «Каталог книг»

## Запуск программы

### Требования
- .NET 7.0 или выше
- SQLite (включен в проект)

### Запуск из командной строки

1. Перейдите в директорию с проектом:
   ```bash
   cd 4лабаООП/Lab4/BookCatalog
   ```

2. Запустите программу с помощью dotnet:
   ```bash
   dotnet run --help
   ```

### Доступные команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `import <file>` | Импорт книг через EF Core | `dotnet run import books.csv` |
| `import_ado <file> [strategy] [maxErrors]` | Импорт через ADO.NET | `dotnet run import_ado books.csv merge 5` |
| `export <format>` | Экспорт в JSON или XML | `dotnet run export json` |
| `add <isbn> <title> <author> <year> <pages>` | Добавить новую книгу | `dotnet run add "123" "Book Title" "Author" "2020" "300"` |
| `update <isbn> <title> <author> <year> <pages>` | Обновить книгу | `dotnet run update "123" "New Title" "Author" "2021" "350"` |
| `delete <isbn>` | Удалить книгу по ISBN | `dotnet run delete "123"` |
| `find <query>` | Поиск книг | `dotnet run find "Author"` |
| `sync [strategy] [maxErrors]` | Синхронизация БД с JSON | `dotnet run sync ask 3` |

### Стратегии импорта и синхронизации

**Для import_ado:**
- `update` - обновлять существующие записи
- `skip` - пропускать дубликаты
- `merge` - объединять поля

**Для sync:**
- `ask` - спрашивать пользователя при конфликтах
- `update_db` - обновлять базу данных
- `update_file` - обновлять файл
- `skip` - пропускать конфликты

## Объяснение работы программы

### Архитектура приложения

1. **Модель данных (Models/Book.cs)**
   - Сущность `Book` с полями: ISBN, Title, Author, Year, Pages
   - ISBN используется как первичный ключ

2. **Контекст базы данных (Data/BooksContext.cs)**
   - Использует Entity Framework Core
   - Работает с SQLite базой данных `books.db`

3. **Команды (Commands/)**
   - `ImportBooks.cs` - импорт через EF Core
   - `ImportBooksAdo.cs` - импорт через ADO.NET
   - `ExportBooks.cs` - экспорт в JSON/XML
   - `AddBook.cs` - добавление книги
   - `UpdateBook.cs` - обновление книги
   - `DeleteBook.cs` - удаление книги
   - `FindBooks.cs` - поиск книг
   - `SyncBooks.cs` - синхронизация БД и файла

4. **Логирование (Logger.cs)**
   - Все операции логируются в `sync.log`
   - Логи включают успешные операции и ошибки

### Процесс работы

1. **Импорт данных**
   - Чтение CSV/XML файла
   - Валидация данных
   - Сохранение в базу данных
   - Логирование результатов

2. **CRUD операции**
   - Добавление, обновление, удаление и поиск книг
   - Все операции обрабатываются через контекст EF Core

3. **Синхронизация**
   - Сравнение данных в БД и JSON файле
   - Разрешение конфликтов по выбранной стратегии
   - Логирование принятых решений

4. **Экспорт данных**
   - Сериализация в JSON или XML формат
   - Сохранение в соответствующий файл

## Проверка работы программы

### Пример 1: Импорт данных из CSV

```bash
dotnet run import_ado books.csv merge 5
```

**Ожидаемый результат:**
- Данные из `books.csv` импортируются в базу данных
- Лог `sync.log` содержит информацию об импорте
- База данных `books.db` создается/обновляется

### Пример 2: Экспорт в JSON

```bash
dotnet run export json
```

**Ожидаемый результат:**
- Создается файл `books.json` с данными всех книг
- Файл содержит все поля: ISBN, Title, Author, Year, Pages

### Пример 3: CRUD операции

```bash
# Добавление книги
dotnet run add "978-3-16-148410-0" "Новая книга" "Автор" "2023" "250"

# Поиск книг
dotnet run find "Автор"

# Обновление книги
dotnet run update "978-3-16-148410-0" "Обновленная книга" "Автор" "2023" "300"

# Удаление книги
dotnet run delete "978-3-16-148410-0"
```

**Ожидаемый результат:**
- Книга добавляется/обновляется/удаляется в базе данных
- Поиск возвращает соответствующие записи

### Пример 4: Синхронизация

```bash
dotnet run sync ask 3
```

**Ожидаемый результат:**
- Программа сравнивает данные в БД и `books.json`
- При конфликтах предлагает выбрать стратегию
- Лог содержит информацию о синхронизации

## Проверка логов

После выполнения любых операций проверьте файл `sync.log`:
```bash
cat sync.log
```

Лог должен содержать:
- Время выполнения операции
- Тип операции (импорт, экспорт, добавление и т.д.)
- Количество обработанных записей
- Информацию об ошибках (если были)

## Проверка базы данных

Для проверки содержимого базы данных можно использовать SQLite командную строку:
```bash
sqlite3 books.db "SELECT * FROM Books;"
```

## Проверка экспортных файлов

Проверьте созданные файлы:
- `books.json` - экспорт в JSON формате
- `books.xml` - экспорт в XML формате

Файлы должны содержать все книги в соответствующем формате.

## Возможные ошибки и их решение

1. **Ошибка подключения к базе данных**
   - Убедитесь, что у вас есть права на запись в директорию
   - Проверьте, что SQLite правильно установлен

2. **Ошибки валидации**
   - Проверьте формат данных в CSV/XML файле
   - Убедитесь, что все обязательные поля заполнены

3. **Ошибки импорта**
   - Проверьте лог `sync.log` для деталей
   - Убедитесь, что файл имеет правильный формат

4. **Ошибки синхронизации**
   - Проверьте, что файл `books.json` существует
   - Убедитесь, что данные в файле и БД совместимы
